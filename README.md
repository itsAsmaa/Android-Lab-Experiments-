## 📖 About

This repository contains all lab experiments and project submissions for **ENCS515 – Advanced Computer Systems Engineering Lab** (2025). The course covers Android application development from the ground up, progressing through UI design, data persistence, networking, and backend integration with Spring Boot.

Each experiment is implemented in **Android Studio (Java)** and follows the official lab manual authored by Eng. Rajaie Imseeh & Dr. Mohammad Hussain (2019), updated by Eng. Ayham Hasheesh & Eng. Tarek Zidan (2025).

## 🧪 Experiments Overview

| # | Experiment | Key Topics |
|---|-----------|------------|
| 1 | **Introduction to Android Programming** | Android Studio setup, Hello World app, Activities, Manifest, `findViewById` |
| 2 | **Android Layouts** | Views, ViewGroups, LinearLayout, ConstraintLayout, UI design |
| 3 | **Using Intents and Notifications** | Explicit/implicit intents, passing data between activities, push notifications |
| 4 | **SQLite Database** | CRUD operations, `SQLiteOpenHelper`, cursor-based data retrieval |
| 5 | **Frame & Tween Animation** | `AnimationDrawable`, `ObjectAnimator`, XML-based animations |
| 6 | **Singleton & Shared Preferences** | Singleton design pattern, persistent key-value storage |
| 7 | **Fragments** | Fragment lifecycle, back stack, inter-fragment communication |
| 8 | **Integrating REST API** | Retrofit, HTTP GET/POST, JSON parsing, API calls in Android |
| 9 | **Spring Boot – Part 1** | Setting up a Spring Boot REST API backend |
| 10 | **Spring Boot – Part 2** | Advanced Spring Boot features, connecting Android frontend to backend |
